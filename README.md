# PortfolioForge

Personal portfolio website, built and maintained by Ellison Naz.

## About

This repository holds the source for my personal portfolio site. It showcases my projects, research, and background in one place.

## Structure

    PortfolioForge/
    ├── index.html
    ├── css/
    ├── js/
    └── assets/

## Setup

Clone the repo:

    git clone https://github.com/ellitellicity-commits/Portfolio-Forge.git

Then open `index.html` locally, or serve it with any static file server.

## Deployment

This site is deployed via GitHub Pages from the `main` branch. It's live at https://ellitellicity-commits.github.io/Portfolio-Forge/
